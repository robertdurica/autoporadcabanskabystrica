# Auto Poradca Banská Bystrica

Statický web pripravený na GitHub Pages.

## Nasadenie
1. Nahrajte celý obsah tohto priečinka do GitHub repozitára.
2. V GitHub-e otvorte **Settings → Pages**.
3. Zvoľte **Deploy from a branch**, vyberte `main` a priečinok `/root`.
4. Po nasadení nastavte vlastnú doménu `www.autoporadcabanskabystrica.sk`.
5. U registrátora domény nastavte DNS podľa pokynov GitHub Pages.

## Pred zverejnením
V dodaných podkladoch boli uvedené:
- telefón: 0918 123 456
- e-mail: autoporadca@email.sk
- pôsobnosť: Banská Bystrica a okolie

Ak sú tieto údaje iba ukážkové, nahraďte ich v `index.html` pred publikovaním. Telefón, e-mail, canonical URL, Open Graph URL a JSON-LD sú už nastavené na zamýšľanú doménu.

Web je bez externých JavaScript knižníc a bez build procesu – stačí nahrať súbory.
